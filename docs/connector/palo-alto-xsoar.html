What you'll need

FieldTypeRequiredSecretDescription
Cortex XSOAR API hoststringYesNoTenant-specific API FQDN, no scheme or path -- e.g. api-abc123.paloaltonetworks.com. Copy it from the cURL example shown when you right-click a generated API key and select 'View Examples' in Settings -> Integrations -> API Keys.
API Key IDstringYesYesThe Key ID shown alongside the generated API key (sent as the x-xdr-auth-id header on every call). Not the key value itself, but stored securely since it identifies the credential.
API key (Standard)stringYesYesStandard-type Cortex XSOAR 8 API key, generated under Settings -> Integrations -> API Keys. Sent as the raw Authorization header value. This connector uses Standard keys only -- Advanced keys require a per-request computed HMAC signature that a static header binding cannot produce; see SKILL.md.
