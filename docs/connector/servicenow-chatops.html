ServiceNow ChatOps

ServiceNow Table API, scoped to one customer-configured table -- creates a verification-request record assigned to a target user for the customer's own ServiceNow ChatOps/Now Actions flow to deliver via Slack/Teams, then polls for a reply; `--yes`-gated create/comment/close writes

What you'll need

FieldTypeRequiredSecretDescription
ServiceNow instance hoststringYesNoServiceNow instance hostname, e.g. mycompany.service-now.com. No scheme (Crogl adds https://).
Target tablestringYesNoThe ServiceNow table this connector creates and reads verification-request records in (e.g. interaction, sc_task, or a custom table). This MUST be a table your ServiceNow ChatOps/Now Actions notification flow is already configured to watch and deliver to Slack/Microsoft Teams -- confirm the exact table with your ServiceNow admin before setting this; this connector does not configure that delivery flow, it only writes records to it. One connector instance targets exactly one table. The table must have an 'assigned_to' reference field (standard on Task-derived tables such as incident, sc_task, interaction; not guaranteed on a fully custom table).
OAuth Client IDstringYesNoClient ID of a ServiceNow OAuth Application Registry entry configured for the Client Credentials grant type (System OAuth > Application Registry).
OAuth Client SecretstringYesYesClient Secret for the same OAuth Application Registry entry.
