FieldTypeRequiredSecretDescription
Tanium Cloud API hoststringYesNoTanium Cloud API host, no scheme or path -- e.g. acme-api.cloud.tanium.com (the '-api' subdomain used by Tanium Gateway). This connector targets Tanium Cloud only; on-prem Tanium API surfaces differ and are not covered.
API tokenstringYesYesTanium API token, sent as the raw value of the 'session' header on every request. Create one from Tanium Console: Administration -> Permissions -> API Tokens. Scope its persona/role to read-only access for Asset, Comply, Patch, and Threat Response.
